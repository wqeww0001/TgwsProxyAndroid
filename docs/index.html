Прямой WebSocket-мост для Telegram на Android

TG WS Proxy поднимает локальный MTProto-сервер на вашем смартфоне и заворачивает трафик Telegram в защищённый TLS 1.3 WebSocket (kws*.web.telegram.org) с резервным пулом Cloudflare CDN и TCP fallback. Банковские приложения, игры и Госуслуги продолжают работать напрямую без VPN.

ЧИСТОЕ ЯДРО V2.5.3
В версии 2.5.3 приложение работает исключительно на едином нативном Rust-мосте MTProto-over-WebSocket (libtgwsproxy.so) с поддержкой отката версий и выбора маршрутизации.

Как пакет проходит от Telegram до дата-центра

Вместо создания виртуального сетевого интерфейса VpnService на весь телефон, приложение открывает локальный сокет только для клиента Telegram.

ШАГ 01 • КЛИЕНТ

Telegram Android

Подключается к 127.0.0.1:1443 по стандартному профилю MTProto Proxy с локальным dd-секретом.

ШАГ 02 • DEOBFUSCATION

Чтение Obfuscated2

Нативное ядро Rust считывает 64-байтный заголовок, извлекает номер дата-центра (DC1..DC5 или 203) и зануляет ключи в памяти после использования.

ШАГ 03 • ТРАНСПОРТ

TLS 1.3 WebSocket (RFC 6455)

Пакеты инкапсулируются в WebSocket-фреймы с проверкой Sec-WebSocket-Accept и уходят через пул прогретых соединений rustls.

ШАГ 04 • ФОЛБЭК

Прямой DC + CF-first

Вы сами выбираете в настройках: подключаться напрямую к kws*.web.telegram.org или использовать пул Cloudflare CDN с прозрачным TCP fallback.

Чем локальный WS-прокси лучше обычного VPN

Обычный VPN заворачивает весь трафик смартфона в зарубежный туннель. TG WS Proxy работает точечно внутри самого Telegram.

Параметр TG WS Proxy Android (v2.5.3) Обычный VPN-клиент
Банковские приложения, Госуслуги, такси Работают напрямую без помех (VPN-слот свободен) Часто блокируют вход из-за чужого IP
Расход заряда батареи Минимальный (~0% при выключенном экране со Smart Standby) Постоянный перехват пакетов всех приложений (TUN/TAP)
Сбор трафика и приватность 100% локально на 127.0.0.1:1443 (исходный код открыт, GPLv3) Весь DNS и трафик проходит через чужой сервер
Каскадная отказоустойчивость Cloudflare CDN + прямой WSS к DC + прямой TCP fallback Один сервер, легко блокируется по IP/сигнатуре
