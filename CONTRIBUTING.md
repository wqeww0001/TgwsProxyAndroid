# Руководство по участию в проекте (Contributing Guide)

Спасибо за ваш интерес к развитию **TgwsProxyAndroid**! Мы приветствуем любой вклад: исправление ошибок, оптимизацию энергопотребления, добавление новых функций, перевод и улучшение документации.

---

## 🛠️ Как внести свой вклад

### 1. Сообщение об ошибках (Bug Reports)
- Перед созданием новой темы проверьте [существующие Issues](https://github.com/wqeww0001/TgwsProxyAndroid/issues), чтобы убедиться, что проблема еще не обсуждается.
- Используйте шаблон **Bug Report** и укажите:
  - Версию приложения (например, 2.4.1) и версию Android.
  - Модель устройства.
  - Шаги для воспроизведения проблемы.
  - Логи (из вкладки «Журнал» в приложении, если применимо).

### 2. Предложение улучшений (Feature Requests)
- Опишите задачу, которую решает предлагаемая функция, и почему она будет полезна пользователям.
- Используйте шаблон **Feature Request**.

### 3. Отправка Pull Request (PR)
1. Сделайте **Fork** репозитория.
2. Создайте новую ветку для ваших изменений:
   `ash
   git checkout -b feature/my-awesome-feature
   # или
   git checkout -b fix/issue-description
   `
3. Внесите изменения с понятными сообщениями коммитов (согласно Conventional Commits: eat: ..., ix: ..., efactor: ...).
4. Убедитесь, что все тесты проходят и проект собирается:
   `ash
   # Проверка Rust ядра
   cargo test --locked

   # Проверка Android приложения
   ./gradlew testDebugUnitTest lintDebug assembleDebug
   `
5. Отправьте Pull Request в ветку main основного репозитория, заполнив шаблон PR.

## 🏗️ Архитектура проекта

- **src/** — кроссплатформенное асинхронное ядро прокси на **Rust + Tokio** (TLS/WebSocket маршрутизация, MTProto криптография, пул соединений, fallback).
- **pp/src/main/java/com/tgwsproxy/android/** — Android-приложение на **Kotlin & Jetpack Compose**:
  - MainActivity.kt — современный декларативный интерфейс с матовым дизайном, вкладками, диалогами и графиками.
  - ProxyService.kt — системный Foreground Service для стабильной фоновой работы с поддержкой Doze/Smart Standby.
  - ProxyTileService.kt — плитка быстрого переключения в шторке Android (Quick Settings Tile).
  - enchmark/ — модуль асинхронного тестирования задержки доменов.
  - config/ — управление профилями, пресетами и экспорт/импорт конфигураций.
  - 	raffic/ — модуль мониторинга и долгосрочного учета трафика.
  - util/ — вспомогательные утилиты (сеть, QR-генератор, обновления, Keystore).
