# Политика конфиденциальности (Privacy Policy)

Последнее обновление: 1 сентября 2026 г.

Проект **TgwsProxyAndroid** является бесплатным программным обеспечением с открытым исходным кодом (Open Source under GNU General Public License v3.0).

Безопасность и приватность данных пользователей являются нашим высшим приоритетом.

---

### 1. Сбор и обработка персональных данных
- Приложение **НЕ собирает, НЕ хранит и НЕ передает** никакие персональные данные пользователей (имена, телефоны, email, IP-адреса, контакты, геолокацию).
- Приложение **НЕ содержит** сторонних рекламных SDK, трекеров, систем аналитики (Google Analytics, Яндекс.Метрика, Firebase Analytics и т.д.).

---

### 2. Принцип работы прокси и шифрование
- Локальный прокси-сервер запускается строго на петлевом интерфейсе устройства (`127.0.0.1:1443`) и недоступен извне.
- Весь трафик между клиентом Telegram и дата-центрами Telegram передается в зашифрованном виде (End-to-End Encryption по протоколу MTProto).
- Секретные ключи (локальный секрет MTProto и секрет Telegram Web Proxy `tproxy-v1`) шифруются в аппаратном хранилище Android Keystore алгоритмом AES-GCM и исключены из облачных резервных копий (`allowBackup="false"`).
- При включённом режиме Cloudflare CDN приложение туннелирует зашифрованный MTProto-трафик через WSS-соединения (порт 443) и периодически обновляет список рабочих доменов с `raw.githubusercontent.com` (приоритет CDN можно отключить в настройках для прямого подключения к дата-центрам Telegram).

---

### 3. Автоматические обновления
- При проверке обновлений приложение делает анонимный HTTPS-запрос к публичному API GitHub Releases (`api.github.com`). Никакие идентификаторы пользователя при этом не передаются.

---

### 4. Разрешения Android
- `INTERNET`: требуется для установки исходящих соединений прокси.
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`: требуется для поддержания непрерывной работы локального прокси в фоне во время использования Telegram.
- `WAKE_LOCK`: удерживает процессор активным во время передачи трафика (автоматически освобождается в режиме Smart Standby при выключенном экране и простое).
- `POST_NOTIFICATIONS`: требуется для отображения статуса службы и кнопки быстрой остановки в шторке уведомлений.
- `RECEIVE_BOOT_COMPLETED`: используется только при включённом пользователем автозапуске прокси после перезагрузки устройства.
- `REQUEST_INSTALL_PACKAGES`: используется для запуска системного установщика Android при обновлении APK внутри приложения.
