# Политика безопасности (Security Policy)

Безопасность и конфиденциальность данных пользователей являются ключевыми приоритетами проекта **TgwsProxyAndroid**.

---

## 🛡️ Поддерживаемые версии

Обновления безопасности и исправления уязвимостей выпускаются для следующих версий:

| Версия | Поддержка безопасности |
| :--- | :--- |
| 2.4.x | :white_check_mark: Активно поддерживается |
| < 2.4.0 | :x: Устарело (рекомендуется обновление) |

---

## 🔒 Встроенные механизмы защиты

1. **Изолированное хранилище ключей (Android Keystore):**
   - Секретный ключ MTProto шифруется с использованием алгоритма AES-GCM и неэкспортируемого ключа аппаратного модуля безопасности Android Keystore.
   - Секреты исключены из резервных копий Android Cloud Backup (llowBackup="false").

2. **Защита процесса автообновления:**
   - Каждое загруженное обновление перед установкой верифицирует packageName и SHA-256 цифровой сертификат подписи разработчика (signingCertificateHistory), исключая подмену APK.

3. **Шифрование и TLS:**
   - Все исходящие TLS/WebSocket соединения валидируются по доверенным корневым сертификатам публичной WebPKI.
   - Локальный прокси по умолчанию привязан строго к петлевому интерфейсу 127.0.0.1, делая его недоступным извне без явного включения пользователем режима раздачи LAN.

## 🚨 Сообщение об уязвимости

Если вы обнаружили потенциальную уязвимость безопасности:
1. **Пожалуйста, не создавайте публичный Issue.**
2. Отправьте конфиденциальный отчет через [GitHub Private Vulnerability Reporting](https://github.com/wqeww0001/TgwsProxyAndroid/security/advisories/new) или свяжитесь с мейнтейнером проекта напрямую.
3. Опишите шаги для воспроизведения и возможное влияние уязвимости.

Мы рассмотрим ваш отчет в кратчайшие сроки и выпустим соответствующее исправление.
